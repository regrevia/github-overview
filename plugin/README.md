# GitHub Overview

一个 DSH 插件，把本机正在跑的 GitHub Overview 看板接给模型：装好之后模型多了一个 `github_overview` 工具，问「我仓库最近的访客」「npm 下载涨了没」「哪些人给我提了 PR」时它读真实数字，不再估。

## 装之前

- 先让看板跑起来：`npx github-overview start`，或者打开桌面端。插件只跟 `127.0.0.1` 上已经监听的那一个实例说话。
- 看板要绑过账号，第一次在页面里用 GitHub 登录一次就好。插件自己不读 token、不读 store、不联网到 GitHub。

## 工具

`github_overview({ repo?, days? })`

- `repo`：`owner/name`，或者 `全部仓库`（也就是不带）看全部。
- `days`：`1` / `7` / `30` / `90`，默认 `7`。超过已采集天数的窗口只覆盖有记录的那几天，返回里 `covered` 会写清楚。

返回访客/浏览、去重访客、克隆、克隆去重、npm 下载（总计与近一周）、按天的序列、14 天漏斗、每个仓库一行、外部贡献和 star 增长，以及这份数据是什么时候同步的。

三种情况会明确报出来，不会编数字：

- 没在看板上跑 → `看板没在运行：先 npx github-overview start，或打开桌面端`
- 看板没绑账号 → `看板还没绑定账号：在页面里用 GitHub 登录一次`
- 绑了但还没同步 → `还没有同步数据：在页面上点一次刷新`

## 端口

依次探测 `4317`–`4321`（CLI 默认 4317，端口被占时会往后挪）。自己改了端口就设 `GITHUB_OVERVIEW_URL=http://127.0.0.1:<端口>`。

## 口径

插件只是转发看板算好的数，所以口径跟着看板：访客是 GitHub 的 14 天去重人数，不跨仓相加；浏览和克隆不相加；没采集的日子留空，不画成 0。
